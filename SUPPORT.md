# Support

Use GitHub Discussions for design questions and integration help. Use GitHub
Issues for reproducible defects and accepted feature proposals. Include the
DeepKeel version, Python version, operating system, minimal reproduction, and
redacted diagnostics.

Do not include API keys, prompts, tool payloads, tenant data, checkpoints, or
other private material. Report suspected vulnerabilities through the private
process in [SECURITY.md](SECURITY.md).

Only the versions listed in the latest release notes receive routine fixes.
Pre-release versions are provided for compatibility testing and may change.
